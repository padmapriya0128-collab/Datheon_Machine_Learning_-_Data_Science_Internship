## Internship Tasks

### Task 1 – Iris Flower Classification

**Objective:** Build a machine learning model to classify iris flowers into different species using their flower measurements.

**Key Activities:**
- Loaded and explored the Iris dataset.
- Performed data preprocessing and exploratory data analysis.
- Visualized relationships between features.
- Trained and compared classification algorithms.
- Evaluated model performance.

**Concepts Learned:** Classification, data visualization, feature analysis, model training, and evaluation.

### Task 2 – House Price Prediction

**Objective:** Develop a machine learning model to predict house prices using housing-related features.

**Key Activities:**
- Loaded and analyzed the housing dataset.
- Performed data cleaning and preprocessing.
- Explored relationships between input features and house prices.
- Trained regression models.
- Compared model performance using evaluation metrics.

**Concepts Learned:** Regression, feature engineering, data preprocessing, and model evaluation.

### Task 3 – Machine Learning Classification

**Objective:** Implement and evaluate machine learning classification techniques using a structured dataset.

**Key Activities:**
- Performed data exploration and preprocessing.
- Split the dataset into training and testing sets.
- Trained classification models.
- Applied cross-validation.
- Compared model performance using classification metrics.

**Concepts Learned:** Classification algorithms, cross-validation, ROC-AUC, accuracy, and model comparison.

### Task 4 – NLP Sentiment Classification

**Objective:** Build a Natural Language Processing model to classify customer reviews as positive or negative.

**Dataset:** Combined sentiment-labelled reviews from Amazon, IMDb, and Yelp.

**Key Activities:**
- Loaded and combined three review datasets.
- Performed text cleaning and preprocessing.
- Converted text into numerical features using TF-IDF.
- Trained Multinomial Naive Bayes and Logistic Regression models.
- Evaluated performance using accuracy, classification reports, and confusion matrices.
- Compared models and implemented sentiment prediction for new reviews.

**Concepts Learned:** Natural Language Processing, text preprocessing, TF-IDF vectorization, sentiment analysis, and text classification.
