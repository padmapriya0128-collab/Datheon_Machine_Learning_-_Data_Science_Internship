# NLP Sentiment Classification

## Project Overview
This project focuses on building a Natural Language Processing (NLP) based Sentiment Classification system using Machine Learning.

The system analyzes customer reviews and classifies them into two categories:
- Positive
- Negative

## Dataset
The project uses the UCI Sentiment Labelled Sentences Dataset.

It combines three datasets:
- Amazon Product Reviews
- IMDb Movie Reviews
- Yelp Restaurant Reviews

Total Records: 3,000

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- NLP
- TF-IDF Vectorization
- Jupyter Notebook

## Data Preprocessing
- Convert text into lowercase
- Remove special characters
- Remove unnecessary spaces
- Transform text using TF-IDF

## Machine Learning Algorithms
1. Multinomial Naive Bayes
2. Logistic Regression

## Model Evaluation
The models are evaluated using:
- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix

## Custom Prediction
The trained model accepts customer reviews and predicts whether the sentiment is Positive or Negative.

## Project Files
- nlp_sentiment_classification.ipynb
- amazon_cells_labelled.txt

- yelp_labelled.txt

- tfidf_vectorizer.pkl

## Conclusion
This project demonstrates how NLP and Machine Learning can be used to analyze customer opinions and automatically classify sentiment from text reviews.
